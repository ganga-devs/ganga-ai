VectorDB
PostgreSQL with an extension is being used as the vector db.

LLM server
Ollama is used to download and serve the models. A nvidia gpu is utilized in case it is found. Else there is a fall back to the cpu.

Embedding models
Embedding models are downloaded from hugging face at run time. This download happens only once during the initial setup process.
